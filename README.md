Bem-vindo(a) ao **Pet Life**!  
Este projeto foi desenvolvido durante o curso **Start na Programação** da One Bit Code, com o objetivo de criar uma aplicação visual e funcional para conectar donos de pets a serviços e produtos de forma simples e intuitiva.

---

## 🚀 Tecnologias utilizadas

- **HTML5** – estrutura semântica do conteúdo
- **CSS3** – estilos e responsividade
- **JavaScript** – interatividade e manipulação do DOM
- **Ferramentas Auxiliares**:
  - `npm` ou `yarn` – gerenciamento de pacotes
  - `Live Server` – preview local no desenvolvimento
  - (Opcional) `GitHub Pages` ou `Vercel` – deploy
